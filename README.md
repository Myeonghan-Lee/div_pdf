# 📄 이수증 PDF 자동 분리 및 이름 변경기

여러 명의 이수증이 하나로 병합된 PDF 파일을 업로드하면, 사람별로 페이지를 분리하고 `이름_생년월일.pdf` 형식으로 파일명을 자동 변환하여 ZIP 파일로 제공하는 Streamlit 기반 웹 애플리케이션입니다.

---

## 🌟 주요 기능

* **PDF 자동 분할**: 다수의 페이지로 구성된 병합 PDF를 1페이지 단위로 자동 분리합니다.
* **텍스트 자동 추출**: 정규표현식을 활용하여 문서 내의 '성명' 및 '생년월일' 정보를 자동으로 읽어옵니다.
* **스마트 네이밍**: 추출된 데이터를 바탕으로 개별 파일의 이름을 `이름_YYYYMMDD.pdf` 형식으로 자동 변경합니다. (예: `홍길동_19900101.pdf`)
* **일괄 다운로드**: 분리 및 이름 변경이 완료된 전체 파일을 하나의 `.zip` 파일로 압축하여 손쉽게 다운로드할 수 있습니다.

---

## 🛠️ 기술 스택

* **Language**: Python
* **Web Framework**: Streamlit
* **PDF Processing**: pypdf
